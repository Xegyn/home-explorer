# 🌀 💡 Fan & Light House Explorer

A kid-friendly, first-person 3D roguelike house simulator focused on **fans and lights**, built with zero external dependencies (pure ES modules, HTML5 Canvas 3D renderer, WebAudio procedural sound effects, and Gamepad + Touch + Keyboard/Mouse support).

## Quick Start (macOS Terminal)

Run a local web server from this directory:

```bash
python3 -m http.server 8080
```

Then open **http://localhost:8080** in Chrome or Safari.

## Controls

- **Walk & Turn**: `W` `A` `S` `D` or `Arrow Keys` (or use the on-screen D-Pad for iPad/touch/mouse)
- **Look Around**: Click and drag anywhere on the 3D view, or press `Q` / `E` / `◀` / `▶`
- **Toggle Fans & Lights**:
  - **Click directly** on any Ceiling Fan, Pull-Chain, Standing Fan, Box Fan, Floor Lamp, or Wall Switch!
  - Or stand near one and press `SPACE` (or click the gold **Use Fan / Light** button).
- **Fan Speeds**: Cycle through `OFF → LOW → MEDIUM → HIGH` with realistic blade spin-up/down inertia and swirling breeze particles.
- **Flashlight**: Press `F`
- **Next Procedural House**: Finish the 3 **House Helper Goals** on the top-right checklist to unlock the glowing green **Front Exit Door**, or press `N` anytime to generate a brand-new house!
- **USB / Bluetooth Gamepad**: Plug in an Xbox, PlayStation DualSense, or Switch Pro controller — Left Stick walks, Right Stick looks, `A / Cross` toggles fans & lights, `Y / Triangle` toggles the flashlight.
